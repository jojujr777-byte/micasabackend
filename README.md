# MiCasa — Full-Stack Interior Design Web Application

MiCasa is a full-stack interior design web application built using Angular and Node.js.

The platform is designed to manage interior design projects and streamline interactions between customers, designers, and administrators.

## Features

- Customer management
- Designer management
- Interior design project management
- Work requests
- Payment management
- Customer and designer profiles
- Administrative workflows

## Technologies Used

- Angular
- Node.js
- JavaScript
- SQL
- HTML
- CSS

## Project Structure

### Frontend
The frontend is developed using Angular.

### Backend
The backend is developed using Node.js and provides APIs for the application.

## Purpose

MiCasa was developed as an interior design management platform to connect customers, designers, and administrators while managing projects and related workflows.
